# Assumptions & Limitations

## Academic Origin

The original Temu logistics case was a Columbia University team project. This repository is a personal portfolio reconstruction and does not claim that all original team work was created solely by me.

## Independent Work

The third-party risk-rating dashboard was completed as an individual assignment.

## Public / Academic Information

The case relies on public information, course frameworks, and student analysis. It does **not** use or claim access to Temu's internal:
- contracts
- carrier allocations
- operating procedures
- confidential performance data
- customer data
- risk-acceptance records

## Synthetic Allocation Scenario

The 1,000-shipment allocation scenario is explicitly synthetic and was added for portfolio demonstration.

It exists to show how:
- a concentration limit can constrain allocation,
- a KPI breach can trigger reallocation,
- operational exceptions can map to escalation and remediation.

It should not be interpreted as Temu's actual routing logic or carrier mix.

## Omitted Business-Value Figures

Some high-impact business-value figures from the classroom presentation are not included in the core portfolio because they require source-level validation before being presented as decision-grade facts.

## Tooling Scope

Python is included as a transparent scoring demonstration based on coursework-level programming experience. The portfolio does not present Python as my primary professional analytics stack.

My strongest verified tools remain Excel / spreadsheet modeling, Power Query, PowerPoint, and business / risk analysis.
